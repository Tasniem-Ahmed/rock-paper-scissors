# Rock Paper Scissors 🎮

## About the Project

This is an early-stage Rock Paper Scissors game built using HTML, CSS, and Vanilla JavaScript.

The project is a result of my own learning and hands-on practice. I wrote the code independently without using AI to generate or write the code. Whenever I encountered something unfamiliar, I relied on traditional search methods to understand the concepts and find the information I needed.

My goal was to apply the JavaScript fundamentals I've learned and turn them into a working project on my own.

## Features

- Play Rock, Paper, Scissors against the computer.
- Random computer choices.
- Win, lose, and tie detection.
- Score tracking for each result.
- Reset button to start a new game.
- Interactive interface with dynamic results.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
